# IP 短视频延伸（自然流量）

> 广告解决"被看见"，IP 解决"被相信"。朋友圈广告里那个人设，就是 IP 的起点。同一张脸，广告里买流量，短视频里攒信任。

## 一、为什么要做（判断标准）

判断要不要做 IP：客户的生意需要"信任"才能成交吗？需要 → 值得做。
五个理由：信任复利、素材工厂（爆款直接做广告素材）、私域入口、降低获客成本、抗风险。

## 二、平台选择

做朋友圈广告的客户，IP 优先从**视频号**开始：同一生态、同一批用户、同一套私域（好友点赞带来社交推荐）。
- 抖音：人群年轻、内容表现力强时加
- 小红书：女性决策为主、需要"种草"、用户爱搜攻略时加
- 起步原则：先把一个平台做到稳定周更 3 条以上，再考虑多平台分发

## 三、IP 定位四问（把人设变成 IP）

1. 我是谁：一句话身份 = 身份 + 年限/数字 + 态度（"做了 11 年家装、只说实话的老周"）
2. 说给谁听：直接用人群画像卡
3. 提供什么价值：避坑、省钱、学方法、看真相、有共鸣——选一个主价值
4. 凭什么信我：年限、案例、资质、现场画面、客户原话——每条视频至少露一个

输出：一句 IP 定位语 = 我是谁 + 帮谁 + 解决什么问题（≤20 字）。

**账号四件套**：名字（人名+领域，如"装修老周"）、头像（与广告/企微同一人同一风格）、简介三行（我是谁/能帮你什么/怎么找我）、背景图（定位语+一个证据）+ 置顶 3 条（我是谁 / 代表作 / 客户案例）。

## 四、内容三支柱与选题

- 专业干货 40%（避坑指南、常见误区、怎么选）→ 建立专业信任
- 真实日常 30%（工地/门店/后厨的一天）→ 亲近真实
- 客户案例 30%（前后对比、客户原话、交付现场，需授权）→ 给证据推咨询

选题五个来源：① 客户最常问的 20 个问题 ② 行业误区与真相 ③ 现场发生的故事 ④ 对标爆款选题 ⑤ 节点与热点。
选题三问：目标人群关心吗？我有资格讲吗？60 秒内能讲清吗？三个"是"才进库。

## 五、爆款拆解与复刻

**爆款看相对值**：比账号近 10 条平均高 5–10 倍，且带来私信/加微。值得拆的：人群行业人设接近、普通人拍的、半年内的。

**八要素拆解**：选题 / 封面标题 / 开头 3 秒 / 结构 / 情绪点 / 节奏 / 画面 / 结尾。

**开头 3 秒 8 种钩子**（与外层文案 7 公式同源）：
1. 身份点名："准备装修的你，先别急着签合同"
2. 反常识："装修最贵的不是材料，是返工"
3. 结果前置："这套 90 平的房子，最后只多花了 300 块"
4. 提问："你知道报价单里哪一项最容易被加钱吗？"
5. 数字清单："签合同前一定要问的 3 个问题"
6. 冲突场景："业主和工长在现场吵起来了，原因是……"
7. 悬念："干了 11 年，这件事我第一次说"
8. 场景代入："周六早上 8 点，我站在一个漏水的卫生间里"

开头三不要：不要"大家好我是谁"、不要铺垫背景、不要先放 logo。

**4 种结构**：问题式（问题→原因→方法→行动）、清单式（总起→123点→金句）、反转式（常见做法→但是→真相→建议）、故事式（场景→冲突→解决→观点）。

**复刻五步法**：选爆款 → 拆骨架（八要素）→ 换血肉（自己的身份、案例、现场、城市、原话）→ 加记忆点（固定开场动作/口头禅/结尾金句）→ 测开头（同内容拍 2–3 个开头）。
复刻≠搬运：学结构、钩子类型、节奏、封面形式；不能碰别人的画面、原文案、肖像、音乐、案例数据。

**30 秒脚本**：0–3s 钩子（正脸近景+动作）→ 3–8s 立人设（一句话凭什么讲）→ 8–25s 主体（每 2–3 秒换景别）→ 25–30s 结尾（金句+一个明确动作）。封面：正脸+大字 ≤12 字。

## 六、用爆款拿流量

**四级火箭**：冷启动（发布后 30 分钟内转发 3 个以上群、员工点赞、评论区自己先留一条引导评论）→ 社交推荐 → 算法推荐 → 付费放大（只给验证过的内容花钱）。

**看 5 个数**（24h / 72h 各看一次，和自己平均值比）：完播率（不行→改开头前 10 秒）、点赞率（选题）、评论率（结尾加提问）、转发率（最强爆款信号）、主页访问/私信/加微（承接）。

**放大四招（一条爆款吃三遍）**：加热投放、剪成 15 秒做广告素材 A/B、一鱼多吃（同选题换开头/场景/案例再拍 3 条）、3 天内开直播承接。

**承接**：视频结尾一个明确动作 → 主页简介与置顶 → 私信自动回复+人工 30 分钟跟进（首句复述视频承诺+给立即可得的东西）→ 企微/社群 → 成交。每条线索标注来自哪条视频。

## 七、30 天节奏

每周 3 条（周一干货 / 周三日常 / 周五案例或复刻）；周日集中拍 3–5 条（约 2 小时），剪辑套模板。
7 天：四件套上线、发第一条；14 天：累计 6 条、复刻第 2 条爆款、私信企微承接就位；30 天：累计 12 条以上、最好的一条做广告素材 A/B、月度复盘"来自内容的线索占比"。

衡量标准：3 个月后看"来自内容的线索占比"和"广告线索成本"的变化，而不是只看粉丝数。
