# 违禁词检测（交付前必跑）

> 过不了审，前面所有工作归零；过了审出问题，代价更大。**每一版文案/素材/落地页在交付前，必须跑一次机扫**，把结果写进方案的合规自查小节。这是硬卡口，不是可选项。

## 跑法

```bash
python3 <skill目录>/scripts/check_compliance.py --spec copy_spec.json
python3 <skill目录>/scripts/check_compliance.py --file 投放策略方案-XXX.md   # 方案全文也扫
python3 <skill目录>/scripts/check_compliance.py --quiet                      # 只看拒审项
python3 <skill目录>/scripts/check_compliance.py --spec detail_copy_spec.json --mode page   # 详情页/落地页文案
```

### 两种扫描模式（别把规则套错对象）

| 模式 | 用在哪 | 套用的规则 |
| --- | --- | --- |
| `--mode outer`（默认） | **朋友圈外层文案** | 全部规范：40 字上限、≤4 行、不允许空格、禁用字符，+ 全部词表 |
| `--mode page` | **详情页 / 落地页文案** | 只查词表（极限词、承诺、微信产品词、诱导加联系方式、教育红线等）——**网页不受 40 字与无空格限制**，不要拿外层排版规则去卡它 |

> 搞错模式会误报一堆"字数超限/空格"，把真正的问题淹没掉。详情页的图与页面用 `page` 模式。
> 反过来，**详情页文案同样要过词表**：落地页也在《广告法》与平台链接内容规范的管辖范围内（《互联网广告管理办法》第十八条：每一级跳转页面都要过合规清单）。

### ⚠️ 扫方案全文（`--file`）的误报是必然的，别当卡口

`--file` 是**按词面精确匹配**的，本意是扫"候选投放文案文档"。但**方案 Markdown 里全是方法论描述**，必然被误命中：

| 方案里的原文 | 命中词 | 为什么是误报 |
| --- | --- | --- |
| `> 大字（= 第一行）` | `第一`（绝对化） | 说的是排版位置，不是宣称 |
| `✅ 无前后对比、无新闻体` | `前后对比` | 正是在说明**没有**用 |
| `**不放二维码**／电话` | `二维码` | 正是在说明**不能**放 |
| `**绝不说**：最便宜、零甲醛` | `最便宜` | 正是在声明**禁用** |
| `第一次月度复盘` | `第一` | 时间序数 |

**所以**：

- **真正的卡口只有一个：`copy_spec.json` / `detail_copy_spec.json`（广告文案的唯一真源）**——这两个文件的 BLOCK 必须归零。
- 方案全文扫描**不作为交付卡口**，只用来"找遗漏"：逐条看 BLOCK 命中，凡是**引号内、或落在否定句与反面示例里**的，判为误报跳过；只有**孤立的、出现在正常叙述句里的**才需要改。
- 汇报时如实写明"方案全文 N 处命中，全部来自方法论文字，属按词面匹配的误报"，**不要谎报为 0**。

- 发现 **BLOCK 级问题 → 退出码 1**，必须改完再交付；改完重跑，直到 BLOCK 归零。
- `WARN` 级（免费、限时、名额、价格夸张、贬低群体…）要逐条人工判断，能删则删、不能删则改为可核实表述。
- `NOTE` 级（涉及数据、名额、活动）不是文案问题，是**举证问题**——要么拿到证明材料，要么删掉数字。

## 三个严重度的含义

| 级别 | 含义 | 处理 |
| --- | --- | --- |
| 🔴 BLOCK 必拒审 | 机审秒拒类：绝对化用语、诱导加微信、微信产品功能词、保证承诺、教育红线、超字数、禁用字符 | **必须改掉**，不留任何一条 |
| 🟠 WARN 高风险 | 免费/限时/稀缺/价格夸张/贬低群体/功效词，可能被拒或被抽检 | 逐条判断，优先改写为可核实表述 |
| 🟡 NOTE 需备案/举证 | 出现金额、数字、名额、活动 | 备齐数据证明与活动备案，否则删数字 |

## 外层文案的硬规范（容易被忽略）

| 项 | 要求 | 说明 |
| --- | --- | --- |
| 字数 | **≤40 个字**（三行合计，含标点） | 微信广告制作规范。超了会被截断或拒审 |
| 行数 | **≤4 行** | 同上 |
| 空格 | **不允许** | 「3分钱」而不是「3 分钱」；「2万」而不是「2 万」 |
| 符号 | 不用破折号「——」；连接号仅限「~」；不用「「」」「【】」；不混用中英文标点 | 直角引号、方括号都会被打回 |
| 标点一致性 | 每行末尾**全部加标点**或**全部不加** | 统一加「。？！」最稳 |
| 折行 | 单个词语/文字不得单独成行 | 不要为了凑行数硬拆句 |
| emoji | 不允许 | — |
| 联系方式 | 不得出现电话、微信号、QQ、URL、二维码、按钮元素 | 图片里也不行，OCR 会抓 |

> ⚠️ 与 `ad-mockup-render.md` 的「每行 ≤22 个中文字」是**两条不同的限制**：22 字是**渲染不截断**的版面限制，40 字是**平台审核**的合规限制。两条都要满足 → 实务上按 **40 字总量 + 每行 ≤22 字** 写。

## 行动指令怎么写（重要）

平台**不允许诱导添加微信/公众号等联系方式**，但**明确支持**下面这几种表述：

✅ 可用：`加企微`｜`加企微群`｜`加客服`｜`加客服群`｜`加客服微信`
❌ 不可用：`加我微信`｜`加微信`｜`加我`｜`私信我`｜`扫码加我`

承接方式：走**平台自带落地页的【商家微信】/加企微组件**；二维码只能出现在平台组件里，**不能印在广告素材上**。

## 微信产品功能词汇（未经授权禁用）

`朋友圈`、`点赞`、`评论`、`公众号`、`视频号`、`小程序`、`微信`、`红包`

→ 写文案时把「发朋友圈」改成「发消息」「在私域里发」；把「朋友圈广告」这类词从外层文案里彻底去掉（广告位本身不需要在文案里自我说明）。

## 教育 / 培训类额外红线

若按教育-职业技能培训类目开户：

- 不得对培训效果作**保证性承诺**（「包过」「学完就能接单」）
- 不得**暗示增加收入**（「月入」「副业」「额外收入」）
- 不支持「**教你赚钱 / 教你如何赚钱 / 引流 / 加粉 / 涨粉 / 养号**」类营销描述
- 不得出现第三方平台信息（抖音、快手、微博）
- 营业执照经营范围须含教育/培训；线上培训另需《增值电信业务经营许可证》
- 落地页**禁止出现加群内容**

→ 若产品是「软件/系统」为主（如 AI 自动投放系统），**优先按软件工具或商务服务类目开户**，避开教育类目的一堆额外限制；培训作为配套服务，广告主推系统能力而非"教你赚钱"。

## 素材与落地页

- 图片文字占比：老规范 ≤20%，近期口径 ≤30%——**大字只留一行**最稳
- 素材**不得模仿微信系统通知、朋友圈界面、来电/未读提示**；**效果图不能直接当素材投**
- 落地页域名需 **ICP 备案**，备案主体与广告账户一致
- 收集信息必须有**可勾选的隐私协议**，不得默认勾选
- 落地页与素材口径一致；外层写什么优惠，落地页就要能兑现

## 词表维护

词表写在 `scripts/check_compliance.py` 的 `RULES` 常量里，按 `(严重度, 类别, 词表)` 组织。平台规则更新时：

1. 在对应类别里增删词
2. 白名单短语加进 `ALLOWLIST`（目前是加企微/加客服系列）
3. 新增类别时同步更新本文件的说明表

> 机扫只能覆盖**词**，覆盖不了**语义**（比如把效果承诺换一种说法）。所以机扫之后仍要按 `compliance.md` 的四层清单人工过一遍。
