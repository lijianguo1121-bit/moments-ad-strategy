# 审核合规与行业红线

> 过不了审，一切都是零；过了审出问题，代价更大。投前 5 分钟过清单，比拒审后改 3 天便宜。

## 零、平台侧硬规范（先过这一关，出自《微信广告制作规范》）

广告法管"词"，平台规范还管"格式"。**下面这些是机审的结构性红线，比极限词更容易被整条毙掉**，写文案时就要遵守：

| 项 | 硬规则 | 常见踩法 |
| --- | --- | --- |
| **字数** | 外层文案**不超过 40 个字、不超过四行** | 写"三行结构"时容易写到 50+ 字，全条折叠 |
| **空格** | **不允许使用空格** | "3 分钱""2 万/月""8 个老板"——数字与汉字之间加空格是重灾区，要写成"3分钱""2万/月" |
| **标点** | 须符合《标点符号用法》；**每行末尾要么全加标点、要么全不加**；中文不与半角标点混用 | 三行里两行有句号、一行没有 |
| **符号** | 不许破折号「——」；连接号仅限「~」「-」；不许 emoji、不许特殊符号 | 用「」直角引号、用「/」、用「——」 |
| **产品功能词** | 未经授权**禁用「朋友圈」「点赞」「评论」「公众号」「微信」「红包」**及其谐音 | 文案里写"发朋友圈""加我微信" |
| **联系方式** | **不得诱导添加微信/公众号等联系方式**；素材禁出现微信号、二维码、VX、二维码、手机号、URL | 第三行动作指令写"加我微信" |
| **可用替代** | 平台**明确支持**「**加企微**、加企微群、加客服微信、加客服、加客服群」，并**通过平台自带落地页的【商家微信】/加企微组件承接** | ✅ 写"点下面加企微"，且素材/落地页都不放二维码 |
| **办公区** | 素材不得模仿微信系统通知、功能性消息提示，不得让人误以为是腾讯/微信官方行为 | 把"朋友圈卡片效果图"直接当素材投 |
| **敏感词** | 「免费」「红包」「抽奖」「关注XXX」「了解XXX」列入不建议使用 | 文案里写"免费领取" |
| **语气** | 不得挑衅、命令、誓言语气（"不买不要点""你该换表了""我发誓"）；不得贬低特定群体（"大龄剩女""民工都能办"） | "先别急着…""你该…"属边界表达，能改陈述句就改 |
| **稀缺** | 禁"仅限今天/最后一天/即将涨价/即将售罄"这类实时性诱导；真实稀缺可用但须兑现 | 名额类表述要活动备案 |

**必做的三件事**：① 定稿后**逐字数 40 字**；② 全文搜「微信 / 朋友圈 / 免费 / 空格」；③ 动作指令统一用「加企微 / 加客服」而不是「加我微信」。

## 一、通用红线

1. **极限词**：最、第一、顶级、独家、国家级、100%、绝对、保证
2. **虚假承诺**：保过、包治、稳赚、无效退款（无依据）、收益承诺、升值承诺
3. **诱导与假稀缺**：不点后悔、"限时最后 1 天"长期挂着
4. **侵权**：未经授权使用他人商标、形象、作品；文案抄袭（AI 生成的也要查重——关键句上线前全网搜一遍）
5. **点名用户**：不用年龄、身份、身体特征点名（"40 岁的你""90 后注意" ✕）；改用场景点名（"孩子刚上小学的家长" ✓）
6. **低俗冒犯**：性暗示、贬低女性或某一类人。拿不准的文案，念给目标人群里的人听，有一个人不舒服就改

## 二、极限词替代写法

不是不能说好，是要用可核实的事实说好：

| 不能说 | 可以说 | 原理 |
| --- | --- | --- |
| 最好/最便宜/最专业 | 做了 15 年 / 签约价=结算价 / 主任医师主刀 | 用年限、承诺、资质代替形容词 |
| 第一/领先/顶级 | 福田开了 8 年、服务过 3000 个家庭 | 本地年限和可核实数量 |
| 100%/绝对/保证 | 写进合同 / 不满意重做 | 可兑现的承诺代替绝对化 |
| 独家/唯一 | 我们自己的施工队，不外包 | 说做法不说地位 |
| 国家级/权威 | 有证书：持 XX 证书；没有：删除 | 有资质出示资质 |
| 立竿见影/一次见效/根治 | 第一节课孩子敢说 3 句 / 当天种当天用 | 说可观察的行为，不说功效 |
| 限时最后一天（长期挂） | 本月只接 8 家，满了等下月（真实） | 稀缺必须真实且兑现 |

注意：AI 会换着说法绕过禁用词（"顶尖""极致"），人工要查同义词。

## 三、重点行业红线速查

| 行业 | 资质要求 | 不能出现 | 可以怎么说 |
| --- | --- | --- | --- |
| 医疗/口腔/医美 | 医疗机构执业许可等前置 | 功效承诺、前后对比、患者证言（部分）、疾病名称滥用 | 医生身份+流程+服务承诺（当天种当天用） |
| 健康/减重/保健 | 相关资质 | 治疗功效、减重数字承诺、对比照 | 生活方式、体验、"她说终于能穿回那条裙子了" |
| 教育培训 | 办学许可等 | 保过、提分、升学、就业承诺 | 课程内容、老师年限、可观察的课堂行为 |
| 金融/理财/贷款 | 金融业务资质 | 收益承诺、无风险、低息诱导 | 资质展示+风险提示+流程说明；年化利率写区间并注"以实际审批为准" |
| 房产 | 预售许可等 | 升值、学区、投资回报承诺 | 位置、户型、交付时间、真实价格 |
| 食品/餐饮 | 食品经营许可 | 治疗功效、"纯天然无添加"（无依据） | 食材来源、做法、人设现场 |
| 家装/建材 | — | 零甲醛、最便宜 | 签约价=结算价、工期写进合同、检测报告 |

## 四、人设与证言合规

- 出镜人书面肖像授权，注明使用范围、渠道、期限
- 顾客证言：真人真事 + 授权 + 可核实
- 专业人士人设：资质真实，头衔不夸大
- 不用 AI 换脸、虚拟人冒充真人；AI 生成人像必须明确标注
- 不用公众人物、影视形象、未授权对比照片

## 五、素材拒审高频点

- 前后对比图暗示效果 → 改用过程、场景和事实描述
- 纯色色块挤压画面超一半 → 色块只做文字底，主体是人和场景
- 新闻截图样式、"揭露真相"大字 → 伪装新闻，拒
- 视频开头与产品无关的内容引流 → 前 3 秒就出现产品/服务场景
- 警示语字号 <25px、模糊、贴边 → ≥25px，放清晰底色与安全区内
- 未授权的演员、名人形象 → 只用已签授权的出镜人

## 六、落地页法规红线（《互联网广告管理办法》2023.5.1 施行）

- **第九条 可识别**：软文式、测评式落地页同样要显著标明"广告"
- **第十条 一键关闭**：弹窗一次就能关掉，不得关后继续弹
- **第十八条 链接内容**：每一级跳转页面都要过一遍合规清单；二跳到失控页面，责任仍在广告主

## 七、四层避坑清单（方案交付前逐项打钩）

| 层 | 必查项 |
| --- | --- |
| 文案 | 无极限词；无收益/升值/疗效/包过承诺；不用年龄或身体特征点名；无低俗冒犯；关键句已查重 |
| 素材 | 出镜人有授权；无前后对比、无新闻体；首帧有钩子；警示语清晰在安全区内 |
| 落地页 | 首屏复述外层承诺；外层写的优惠名额落地页有对应；手机打开 3 秒内；需要时标明"广告"；弹窗一键可关 |
| 承接 | 承接人到位；5 分钟响应；首句话术对齐外层；每条线索有记录 |
| 资质 | 行业资质、广告审查文号、肖像授权书齐全，落地页资质与外层一致 |

清单要查三处：外层文案、素材上的大字、落地页首屏——任何一处有问题都会被拒。任何一层打不了钩，就不上线。

## 八、拒审后的标准处理流程

1. 看拒审原因，原文复制到处理记录
2. 对照清单定位：文案/大字/落地页三处逐一查
3. 用替代写法表改，同义词一起查
4. 重提，记录第几次、改了什么
5. 同一原因连续拒 2 次 → 升级合规专员，必要时换表述方向而非换词
