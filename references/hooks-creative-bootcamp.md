# 钩子与素材制作方法论（实战特训营·一天版）

> 源自《朋友圈广告投放实战特训营》一天版：上午练钩子，下午做素材。交付物 = 钩子清单 + 素材脚本/分镜。

## 一、钩子：先让对的人停下来

### 底层认知
- 用户刷到广告只给 1 秒钟；第一句话没说到他，后面的卖点没机会出场。
- 钩子不是花招，是一句"这说的就是我"。
- **好钩子 = 对的人 + 真实场景 + 清楚收获**：先说他是谁，再说他遇到什么，最后告诉他看下去能得到什么。

### 四种开场（选最适合产品的一种，不用全塞进一条）

| # | 开场方式 | 示例 |
|---|---|---|
| 01 | 点名人群 | 准备装修的业主，先看这一步 |
| 02 | 提具体问题 | 报价单里这三项，你都看过吗？ |
| 03 | 还原场景 | 昨天有位客户进店，先问了这句话 |
| 04 | 说清收获 | 看完这张清单，知道先检查哪里 |

### 把"我们很专业"改成"你马上用得上"

少讲自己多厉害，多帮用户解决一个具体问题：

| 太空（用户没感觉） | 具体（用户听得懂） |
|---|---|
| 专业团队，品质保障 | 准备投放的老板，先把这三项准备好 |
| 一站式服务，值得信赖 | 第一次咨询，先问清这两件事 |
| 多年经验，口碑之选 | 预算有限，先拍一条能讲清卖点的视频 |

### 能带来咨询的钩子，有四个零件
1. **对人**：点出目标客户，而不是"所有人"
2. **对事**：说一个真实发生的问题或场景
3. **有收获**：看完能拿到方法、清单或判断依据
4. **有依据**：承诺能做到，素材和页面能兑现

### 钩子自检四问（发布前逐条过）
1. 说给谁听？目标客户能不能一眼认出自己？
2. 说的是真事吗？有没有具体的场景、问题或证据？
3. 后面接得上吗？视频内容、页面和服务能不能兑现？
4. 有没有说过头？去掉无法证明的保证、极限词和夸大结果。

> 把钩子写得更具体，通常比写得更夸张更有效。

### 钩子产出要求
同一个卖点，从人群、问题、场景三个方向各写 1 条，共 3 条；标出最想测试的 1 条。写法：① 谁最需要这款产品 → ② 他最近遇到的具体问题 → ③ 看完能得到的实际帮助。

## 二、素材：把钩子拍成一条看得懂的素材

目标：一条 15–30 秒视频脚本与分镜。让画面证明卖点，让下一步行动足够清楚。

### 五步走（每一步只承担一个任务）
1. **开头**：一句钩子，点明人群或问题
2. **场景**：让用户看到问题发生在哪
3. **办法**：讲清产品/服务如何帮忙
4. **证据**：展示过程、细节或可核实信息
5. **行动**：告诉用户下一步怎么咨询或了解

### 手机拍摄：人、货、场拍清楚（手机就够用，真实 > 复杂转场）
- **人**：出镜人身份真实，表达自然
- **货**：让产品关键细节看得见
- **场**：选和使用场景有关的真实环境

### 画面设计：素材不是海报，一屏只讲一个重点

| 常见问题 | 更清楚的做法 |
|---|---|
| 整屏都是小字 | 保留一个主标题和一个卖点 |
| 同时塞进多个卖点 | 主体放大，背景做减法 |
| 背景热闹，产品看不清 | 字幕短、对比足、重点突出 |

### 四镜头分镜（按脚本拍，不到现场临时想画面）
1. **镜头 1 · 开场**：正脸/产品特写，直接说钩子
2. **镜头 2 · 场景**：拍用户熟悉的真实场景
3. **镜头 3 · 证明**：展示产品细节或服务过程
4. **镜头 4 · 收尾**：一句总结 + 一个清楚的行动

### 文案与字幕（字幕只帮抓重点，不盖住画面；一句一行，跟口播走）
- 开头字幕：把钩子里的关键词放大
- 核心卖点：用短句说清一件事
- 证据信息：数据或结果有来源、有条件
- 行动指令：告诉用户点哪里、咨询什么

### 3 秒互评测试（陌生用户能不能马上看懂）
1. 第一眼：以为这条广告在说什么？
2. 记住了哪个卖点？为什么？
3. 看完知道下一步可以做什么吗？
→ 产出：一条要保留的点 + 一条马上修改的点。

### 发布前五项检查
1. **事实**：产品信息、数据、价格有依据
2. **画面**：清晰稳定，主体突出
3. **表达**：开头和产品相关，承诺做得到
4. **授权**：肖像、音乐、字体、案例素材确认使用权
5. **承接**：落地页和咨询流程能接住用户

## 三、结课行动节奏（给客户的落地建议）

- 钩子：留下 3 条，先测最清楚的一条
- 素材：按脚本拍一版，检查画面和承接
- 案例：按行业规则核对事实、资质和表达
- **7 天内**：完成拍摄、审核、上线准备，并约一次复盘
