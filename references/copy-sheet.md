# 文案一键复制页（copy sheet）

> 交付文案时**必须**同时给一个 HTML 复制页：客户拿到文案是为了去做海报、给设计、填投放后台——让他「选中+复制」是反人性的，点一下按钮就该进剪贴板。这是默认动作，不用等用户开口。

## 为什么要这个页

- 海报 / 设计稿 / 投放后台都要**纯文本**的文案，Markdown 里的 `**`、`>`、表格竖线会一起被粘进去；
- 文案条数变多后（默认 10 条），从长文档里逐条挑、逐条选，很容易选多选少；
- 复制页同时充当**文案确认单**：公式、痛点、归属计划、大字、配图说明都在一张卡上，客户一眼能看完一条广告的全部信息。

## 流程

写一个 `copy_spec.json`（结构见脚本 docstring），然后：

```bash
python3 <skill目录>/scripts/render_copy_sheet.py --spec copy_spec.json
```

脚本输出一个**自包含 HTML**（无外部依赖、无网络请求，可直接双击打开或发给客户）。

## 每张卡包含

| 元素 | 说明 |
| --- | --- |
| 编号 + 公式标签 + 归属计划 | 方便对着投放计划表分派 |
| 针对痛点 | 一行小字 |
| 三行文案 | 纯文本展示，**复制文案**按钮一次复制三行 |
| 大字预览 | 分段强调色渲染（`accent: true` 的段落用品牌色） |
| 配图说明 | 复制配图说明按钮 |
| 复制这一条全部 | 编号/公式/痛点/三行/大字/配图 一次性打包复制 |

顶部两个全局按钮：**复制全部 N 条**（带标题的完整打包）、**只复制全部三行文案**（最常用，直接给设计）。

## copy_spec.json 最小示例

```json
{
  "brand": "IMAI · AI 投放营销",
  "persona": "陈斯克",
  "title": "朋友圈广告外层文案",
  "out": "/abs/path/文案-可复制.html",
  "ads": [
    {
      "no": 1,
      "formula": "提问",
      "pain": "获客成本越来越贵",
      "plan": "计划B",
      "copy": ["广告费花了，客户没来？", "两万的投流师，我自己都看不懂。", "点下面加企微，领行业投放账。"],
      "dazi": [{"t": "还在买线索的老板"}, {"t": "，先停一下", "accent": true}],
      "note": "配图：陈斯克 + 投放后台大屏 + 手指屏幕"
    }
  ]
}
```

## 与其他产出的关系

- `投放策略方案-<公司名>.md` —— 方案全文（第 3 节含文案，带公式与痛点标注）
- `文案-可复制.html` —— **本页**，从方案第 3 节抽出来做成交付工具
- `ad_effects/*.png` —— 效果图，确认方向用

三个文件的文案必须是**同一份**：改了方案里的文案，就重跑本页和效果图，别只改一处。

## 硬性检查（生成后过一遍）

1. 复制内容里**不含任何 Markdown 符号**（`**`、`#`、`|`、`>`）——粘到设计工具里不该带脏字符
2. 每行文案 ≤22 个中文字（与效果图同一限制，超了会截断）
3. 每条文案的**编号连续、公式标签正确**、归属计划与方案第 6 节一致
4. 页面可直接双击打开（file:// 协议下剪贴板 API 受限时会自动降级到 execCommand，两种都要能复制）
