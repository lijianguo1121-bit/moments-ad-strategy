# 广告效果图生成（配图 + 朋友圈卡片渲染）

> 方案里的外层文案和素材需求单，必须变成"所见即所得"的朋友圈广告效果图，与方案一起交付——这是默认动作，不用等用户开口。图片方便客户确认方向后再实拍。

## 流程（两步）

### 第 1 步：生成场景配图（image_generation 插件）

每条文案生成 1 张方形场景图（1024x1024）。提示词配方：

```
真实生活感照片：<人设穿着与身份> 在 <场景> <动作>，<氛围/光线>，
浅景深，画面顶部留有干净的浅色空间，无任何文字水印，手机实拍质感
```

要点：
- **不要在提示词里要求文字**——AI 生成的中文大字不可靠，文字统一在第 2 步用脚本叠加
- **避免儿童正脸**：含儿童脸部的生成请求常被平台拦截（HTTP 424），且真实投放中儿童出镜需家长授权；改用"孩子的小手""背影""手部特写"等构图
- 顶部留白是给大字预留的位置
- 若 image_generation 插件不可用，跳过本流程并告知用户，不要伪造图片

### 第 2 步：渲染朋友圈卡片（scripts/render_ad_mockup.py）

写一个 spec.json（结构见脚本 docstring），然后：

```bash
python3 <skill目录>/scripts/render_ad_mockup.py --spec spec.json
```

每张卡片包含：人设头像（圆形单字+品牌色）、昵称、副标题、三行文案、带大字的配图、右上角"广告"标识、时间与点赞评论栏。

## 大字（配图上的文案）设计规范

1. **内容 = 外层文案第一行**，≤15 字，缩略图也要能读
2. **分段强调**：数字、价格、关键词用强调色（脚本自动处理，`accent: true`），其余白色
3. **字体重**：脚本自动用 NotoSansCJKsc-Bold（找不到则回退 Hiragino Sans GB W6），不要用细体
4. **可读性**：脚本自动加顶部渐变压暗带 + 半透明圆角底衬 + 细描边；不要再手动加花哨描边、爆炸贴、边框 logo
5. 一屏只讲一个重点——大字只有一行

## 合规提醒

- AI 生成的配图自带"AI生成"水印，**保留它**：按合规要求 AI 人像素材必须标注；交付时提醒客户——效果图仅用于确认方向，正式投放应换成实拍素材（人设本人出镜是信任核心）
- 效果图里的价格、承诺必须与方案文案一致，不要因为"好看"临时改文案
